# UOM 助手

**v1.3.1 · Chrome / Edge 扩展 · 本地验证码识别**

在 UOM 页面自动识别并填入图形验证码，并在二级菜单提供培训课程选择及提交控制。所有操作集中在网页悬浮面板中。

## 功能

- 支持单步加减乘除图形验证码，自动填入计算结果（含负数、有限小数）；表达式不完整或无法确认时保留为空。
- 修复透明图片识别及异常长字符串误填；更新扩展后需重启本地识别服务。

- 首页开关控制全站图形验证码自动填入，设置保存在扩展本地并同步到已打开的 UOM 页面。
- 自动配对验证码图片与输入框，支持动态弹窗、路由切换及图片刷新；保留手动输入。验证码弹窗填入成功后自动点击唯一可用的“确定/确认/验证”按钮，同一张图片只确认一次。
- 培训功能位于“培训助手”二级菜单，可返回首页而不中断已有培训任务。
- 图片须能由页面读取；短信、滑块、点选和无法配对的验证码由用户操作。

- 普通模式：识别并提交，等待响应，失败后冷却 300ms 再继续。
- 高并发模式：以 **200ms** 间隔推进提交，限制未完成请求的数量。
- 插件主动打开弹窗、刷新验证码及提交操作，共用不小于 **200ms** 的操作间隔。
- 支持课程选择、验证码刷新和手动提交。
- 切换课程或模式时停止当前任务；关闭面板时停止并释放页面绑定。
- 本地双模型识别，提供浏览器备用识别和成功提示音。

200ms 是插件主动调用页面操作的最小间隔；等待响应、识别及冷却可能让实际间隔更长。平台页面方法内部产生的请求由平台自身实现决定。

## 环境要求

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 64 位 |
| 浏览器 | Chrome 或 Microsoft Edge，Chromium 111 或更新版本 |
| Python | Python 3.12，加入 PATH |
| 本地服务 | `127.0.0.1:8899` 端口可用 |
| 首次安装 | 能访问 PyPI 下载依赖 |

## 安装

### 1. 下载并解压

从本仓库 Releases 下载 `UOM-Helper-v1.3.1.zip`，解压到固定位置。下面的安装与启动脚本均位于 `extension/` 文件夹。

### 2. 安装本地识别服务

双击 `extension/INSTALL_AI_SERVER.bat`。脚本会在发布文件夹旁的 `UOM-Helper-AI/.venv` 创建 Python 环境，按 `requirements.lock.txt` 安装固定依赖。环境放在浏览器扩展目录外，启动时禁用字节码缓存，避免 `__pycache__` 导致扩展加载失败。

安装只需进行一次。安装失败时检查 Python 版本、PATH 与 PyPI 网络连接。

### 3. 启动识别服务

双击 `extension/START_AI_SERVER.bat`，等待模型加载完成。保持窗口运行。

服务地址：`http://127.0.0.1:8899`。浏览器访问 `/health` 可查看状态；正常状态为 `status: "ok"`，版本为 `1.3.1`。

### 4. 加载浏览器扩展

1. Edge 打开 `edge://extensions/`，Chrome 打开 `chrome://extensions/`。
2. 开启开发者模式。
3. 选择“加载解压缩的扩展程序”，定位到 `extension/`，该目录内应有 `manifest.json`。
4. 进入 [UOM 平台](https://uom.caac.gov.cn/)，登录并打开视频培训课程列表。

## 使用

更新后先在扩展管理页面点击重新加载，再刷新 UOM 网页。首页显示检测到的验证码数量、填入次数及具体错误。若显示 AI 离线，请运行本地识别服务；可点击“重新识别当前验证码”再次尝试。

1. 首页可开关“自动填入并确认图形验证码”；使用培训功能时点击“培训助手”，等待连接到课程列表。
2. 在下拉框中确认目标课程，也可直接点击页面课程来同步选择。
3. 选择普通模式或高并发模式。
4. 点击“开始任务”。
5. 点击“停止任务”结束自动操作。关闭面板也会停止，刷新页面可重新显示。

切换课程或模式会停止任务，确认选择后重新开始。手动提交与自动任务互斥；连续手动操作也受 200ms 间隔限制。

已经由平台页面发出的请求无法通过关闭弹窗撤回。提交超过 10 秒没有响应时，插件停止新增操作，请先确认页面结果。
