# UOM 助手

**v1.4 · Windows · Chrome / Edge**

UOM 助手是一款用于 [UOM 平台](https://uom.caac.gov.cn/)的浏览器扩展，提供姓名水印隐私保护、图形验证码辅助和视频培训辅助功能。主要操作都在网页右侧的悬浮面板中完成。

安装包：[UOM-Helper-v1.4.zip](https://github.com/Ender-gk/UOM-Helper/releases/download/v1.4/UOM-Helper-v1.4.zip)。校验文件和版本说明见 [v1.4 发布页面](https://github.com/Ender-gk/UOM-Helper/releases/tag/v1.4)。

## 功能介绍

### 水印隐私

**只隐藏真实姓名，不移除水印。** 账号、日期及其余水印内容保留，原有重复分布、倾斜角度、颜色和透明度设置继续使用，以维持水印的账号标记、日期提示及覆盖效果。

该功能默认启用，适用于地图、飞行活动申请等使用平台公共水印绘制方式的页面。仅调整本机页面显示，不修改账户资料、业务数据或服务端记录。重新加载扩展后，刷新网页即可生效。

### 验证码辅助

- 自动识别页面中的图形验证码，并填入对应输入框。
- 支持单步加、减、乘、除验证码，填入计算结果。
- 验证码弹窗填入成功后，自动点击可用的“确定”“确认”或“验证”按钮；同一张图片只确认一次。
- 支持动态弹窗、图片刷新和输入框清空后重新填入，保留已有的手动输入。
- 首页开关统一控制自动填入与确认，设置会保存并同步到已打开的 UOM 页面。

自动确认仅用于可明确匹配的验证码弹窗。登录、注册等完整表单仍需手动完成。短信、滑块、点选及无法读取的验证码不支持自动处理；无法可靠识别时，输入框会保持为空。

### 培训助手

从面板首页进入“培训助手”二级菜单，可以选择课程、启动或停止任务，也可以刷新验证码、手动提交。

| 模式 | 工作方式 |
| --- | --- |
| 普通模式 | 识别并提交，等待响应；失败后冷却 300ms 再继续。 |
| 高并发模式 | 按不小于 200ms 的间隔推进提交，并限制未完成请求的数量。 |

插件主动操作的最小间隔为 **200ms**。识别、等待响应和冷却会让实际间隔更长，平台页面内部产生的请求由平台自身决定。

## 环境要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 64 位 |
| 浏览器 | Chrome 或 Microsoft Edge，Chromium 111 或更新版本 |
| Python | Python 3.12，安装时加入 PATH |
| 网络 | 首次安装依赖时能够访问 PyPI |
| 本地端口 | `127.0.0.1:8899` 可用 |

扩展与本地识别服务需要配合使用。每次使用前先启动识别服务，并保持服务窗口运行。

## 安装与启动

### 1. 下载并解压

下载上方的安装包，解压到固定位置。以下脚本均位于解压后的 `extension` 文件夹中。

### 2. 安装识别服务

双击 `INSTALL_AI_SERVER.bat`，等待依赖安装完成。此步骤通常只需执行一次。

安装脚本会把 Python 环境放在发布文件夹旁的 `UOM-Helper-AI` 文件夹中，与浏览器扩展目录分开。请保留这个文件夹。

### 3. 启动识别服务

双击 `START_AI_SERVER.bat`，等待模型加载完成，保持窗口运行。

可以访问 [本地服务状态](http://127.0.0.1:8899/health)检查是否启动成功：正常状态为 `status: "ok"`。网页面板也会显示“AI 在线”。

### 4. 加载浏览器扩展

1. Edge 打开 `edge://extensions/`；Chrome 打开 `chrome://extensions/`。
2. 开启“开发者模式”。
3. 点击“加载解压缩的扩展程序”，选择解压后的 **`extension` 文件夹**，该文件夹内应有 `manifest.json`。
4. 打开 UOM 平台。页面右侧出现悬浮面板后即可使用。

## 使用方法

### 自动填入与确认

在面板首页开启“自动填入并确认图形验证码”，再进入信息查询等需要验证码的页面。面板会显示检测数量、填入次数和当前状态。

需要再次尝试时，点击“重新识别当前验证码”。如果希望手动操作，关闭首页开关即可。

### 视频培训

1. 打开 UOM 视频培训课程列表，进入面板中的“培训助手”。
2. 选择目标课程和运行模式。
3. 点击“开始任务”；需要结束时点击“停止任务”。

切换课程或模式会停止当前任务，确认选择后需重新开始。返回面板首页不会中断培训任务；关闭整个面板会停止任务，刷新网页可重新显示。

手动提交与自动任务互斥。提交超过 10 秒没有响应时，插件停止新增操作，请先确认平台结果。已经发出的请求无法撤回。

## 更新方法

1. 停止当前任务，关闭本地识别服务窗口。
2. 下载新版安装包并解压。
3. 如依赖有变化，执行新版的 `INSTALL_AI_SERVER.bat`，然后运行 `START_AI_SERVER.bat`。
4. 在扩展管理页面重新加载扩展；若解压位置改变，重新选择新版的 `extension` 文件夹。
5. 刷新已打开的 UOM 网页。
